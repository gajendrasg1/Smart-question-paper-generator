# 📝 Smart Question Paper Generator

A **Smart Question Paper Generator** is a web-based application developed using **Python and Flask** that automatically generates question papers based on the selected subject, topics, difficulty level, and question requirements.

The main goal of this project is to reduce the time and effort required for teachers or users to manually prepare question papers.

---

## 🚀 Features

* 📚 Generate question papers automatically
* 🎯 Select subject and topics
* 📊 Support different difficulty levels
* 🔢 Specify the number of questions
* 🧠 Generate application-oriented questions
* 📄 Generate and download question papers as PDF
* 🌐 Simple and user-friendly web interface
* ⚡ Fast question paper generation
* 🔄 Different question papers can be generated for different topics

## ⚙️ How It Works

The system follows these basic steps:

```text
User
  ↓
Select Subject
  ↓
Select Topics
  ↓
Select Difficulty / Requirements
  ↓
Generate Questions
  ↓
Create Question Paper
  ↓
Generate PDF
  ↓
Download Question Paper
```

## 💻 Installation

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

Go inside the project folder:

```bash
cd Smart-Question-Paper-Generator
```

---

### 2. Install Required Packages

Make sure Python is installed on your computer.

Install the required dependencies:

```bash
pip install flask fpdf
```

Or, if `requirements.txt` is available:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

Run the Flask application:

```bash
python app.py
```

You should see something similar to:

```text
* Running on http://127.0.0.1:5000
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```

## 📄 Generating a Question Paper

1. Open the application in a browser.
2. Select the required **subject**.
3. Select or enter the required **topics**.
4. Choose the required difficulty level.
5. Specify the number of questions.
6. Click the **Generate Question Paper** button.
7. The system generates the question paper.
8. Download the generated question paper as a PDF.
